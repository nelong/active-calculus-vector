Definition 13.2.4.

A vector field in \(2\)-space is a function whose value at a point \((x,y)\) is a \(2\)-dimensional vector \(\vF(x,y)\text{.}\) Similarly, in \(3\)-space, a vector field is a function \(\vF(x,y,z)\) whose value at the point \((x,y,z)\) is a \(3\)-dimensional vector.
