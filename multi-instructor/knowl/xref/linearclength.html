Example 10.4.8.

In this example, we look at a linear path and explore how to write a parameterization that moves with unit speed. We will look at the parameterization of the line through \((1,2,3)\) and \((2,0,5)\text{.}\) We are using these values to make the calculations less abstract but there is nothing special about these values and the methods will work for any linear parameterization. In Example 10.4.6, we calculate that the length of the path of the parameterization in this case is 3.
🔗
We want to convert this to a parameterization with unit speed. To think of this another way, we are aiming to have the parameter value when we reach the point \((2,0,5)\) be equal to the distance from the base point \((1,2,3)\text{.}\) This will mean we seek a parameterization \(\vr_1(s)\) where the domain \(0\leq s\leq 3\) corresponds to the line segment from \((1,2,3)\) to \((2,0,5)\text{.}\) The speed of our original parameterization is
\begin{equation*} \vecmag{\vr\, '(t)}=\vecmag{\frac{d\vr}{dt}}=\vecmag{\langle 1,-2,2\rangle}=\sqrt{9}=3\text{.} \end{equation*}
This means that we need to adjust our parameterization to travel \(3\) times slower, which can be accomplished by replacing \(t\) in our parameterization with \(s=t/3\text{.}\) In other words, we adjust the parameter used to make sure the speed with respect to the new parameter will be one. This adjustment is easy to do because the amount we needed to change the parameter did not change at different times.
🔗
Our proposed unit speed parameterization is
\begin{equation*} \vr_1(s)= \vr\left(\frac{t}{3}\right) \langle 1,2,3\rangle + \left(\frac{t}{3}\right) \langle 1,-2,2 \rangle\text{.} \end{equation*}
Computing the speed here gives
\begin{equation*} \vecmag{\vr_1(s)}=\vecmag{\frac{1}{3}=\langle 1,-2,2\rangle}=\frac{\sqrt{9}}{3}=1\text{.} \end{equation*}
Algebraically, we can describe this change by thinking of \(\vr(t)\) as the “old” parameterization with parameter \(t\text{,}\) and we aim to replace \(t\) with a function \(s(t)\) so that \(\vecmag{\vr_1\, '(s(t))}=1\) for all \(t\text{.}\) For this linear path, the choice of \(s(t) = t/3\) means that applying the chain rule to \(\vecmag{\vr_1\, '(s)}\) gives
\begin{equation} \vecmag{\vr_1\, '(s(t))}= \vecmag{\frac{d\vr}{ds}} \left\vert{\frac{ds}{dt}}\right\vert=3 \frac{1}{3} =1\text{.}\tag{10.4.2} \end{equation}
