The discriminant of a function of two variables is
\begin{equation*} D = f_{xx}(x_0,y_0) f_{yy}(x_0,y_0) - f_{xy}(x_0,y_0)^2 \text{.} \end{equation*}
If the discriminant is negative, then the concavity will change depending on direction. On the other hand, if the discriminant is positive, then all directions have the same concavity. To illustrate this, we consider a few cases:
  • If \(f_{xx}(x_0,y_0)\) and \(f_{yy}(x_0,y_0)\) have different signs or at least one unmixed second partial is zero, then the discriminant is negative because the second term in \(D\) is always negative. This is the case of the saddle shown above: one coordinate direction is concave up and one is concave down. In this situation, we do not have an extreme point.
    🔗
    🔗
  • If \(f_{xx}(x_0,y_0)\) and \(f_{yy}(x_0,y_0)\) are both positive or both negative, then the first term is positive. If our coordinate directions have the same concavity, then we will need to see if there is enough twist in the surface to change the concavity for directions between the coordinate axes. In other words, if \(f_{xx}(x_0,y_0) f_{yy}(x_0,y_0) \lt f_{xy}(x_0,y_0)^2\text{,}\) there is enough twist to have some direction to have different concavity from the coordinate directions.
    🔗
    🔗
  • If \(f_{xx}(x_0,y_0) f_{yy}(x_0,y_0) \gt f_{xy}(x_0,y_0)^2\text{,}\) then there is not enough twist between the coordinate directions and every direction has the same concavity.
