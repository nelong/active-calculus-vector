Exercise 9.

In this exercise, we want to graphically identify when a given plot can be expressed as:
  • \(y\) as a function of \(x\text{,}\) but \(x\) cannot be written as a function of \(y\)
    🔗
  • \(x\) as a function of \(y\text{,}\) but \(y\) cannot be written as a function of \(x\)
    🔗
  • \(y\) as a function of \(x\) and x as a function of y
    🔗
  • neither \(y\) as a function of \(x\) nor x as a function of y
    🔗
🔗
For each graph in Figure 9.2.15, state which of the four options above applies to whether the graph can be expressed with each coordinate being a function of the other or not. If the graph cannot be expressed with \(y\) as a function of \(x\text{,}\) write a sentence about what property you used to determine this. If the graph cannot be expressed with \(x\) as a function of \(y\text{,}\) write a sentence about what property you used to determine this.
